Links

A website consists of several web pages that give you access to a vast amount of information. A key feature of the World Wide Web, allowing users to navigate between web pages, files, images, or sections within the same page, is called Hyperlinks. Typically, images, text, and navigation across the internet are connected using hyperlinks, which appear as colored, underlined text and are essential for accessing vast amounts of information online.

Types of Linking

There are two types of linking in HTML as discussed below:

  • Internal Linking: When one part of a web page is linked to another section on the same page, it is called internal linking.
  • External Linking: When one web page is linked to another web page or website, it is called external linking.

Anchor <a> Tag

In HTML, the anchor, <a> tag is used to create hyperlinks that allow users to click on text or elements to navigate to another web page or document. It is a container tag, meaning it requires a closing tag.

  • To jump from one page to activate the link
  • To link to another section within the same web page
  • To link to another page within the same website
  • To link to another page or website anywhere on the internet

Href Attribute

You can create a hyperlink in a document with the <a> (anchor) element. The href attribute of the <a> tag specifies the destination of the link, which can be another document, a resource, or a specific place within the same or another document.

Syntax:

<a href="URL" > value </a>

Where URL:

  • It points to another website like <a href="http://www.kips.in">Kips</a>
  • It points to a file within a website (like <a href="http://www.kips.in">
  • It points to an email address (like <a href="mailto:info@kips.in"> )
